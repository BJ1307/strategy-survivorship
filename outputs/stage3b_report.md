# Stage 3B 报告：随机失效时间的有限诊断

本文件由 `python -m strategy_survivorship.run_stage3b` 自动生成，所有数字取自同一次运行的结果表。

## 1. 本轮的设定与覆盖范围

```
    theta_t = s   当 t <= T
    theta_t = 0   当 t >  T
```

T 是**最后一个有效交易日**。设定为固定 T ∈ {0, 126, 252}、随机 T ~ 均匀分布于整数交易日 0..252，以及 T=∞ 的始终有效对照。

**这是“上线后一年内失效”的有限覆盖实验。**T ≤ 252，因此每个设定都有完整的 252 天失效后观察期，落在 504 天总期限之内。**不能**把它描述成已经完成了 0–5 年或 0–10 年的寿命研究。

- T **独立于**噪声、潜在波动率与跳跃；真实 T 只供生成器与评分使用。
- 模型持续接收收益：在 T 时**不**重置先验、累计证据、方差估计或任何窗口。
- 静态两状态分类器在切换数据上的 q，本报告称为**工作失效分数**，不把它解释成正确建模了状态切换后的真实后验概率。

D=252、H=504、年化基础波动率 10%、初始先验 0.5，以及全部检测器参数保持不变。两个噪声情境（独立高斯对照、SV+跳跃（主情境）），五个既有方法，s ∈ {1, 0.6}。

## 2. 门槛与抽样

- 门槛**统一读取** `stage3a_thresholds.csv` 中对应方法、情境、Sharpe 与预算的 **504 日**门槛。不混用 Stage 3A.1 的短期门槛，**不按真实 T 单独校准**——真实失效时间在实践中不可得。
- 保留 α ∈ {0.05, 0.15}；所有路径总监测期不超过 504 天。
- 每个噪声情境使用新的独立测试数据：10000 条始终有效对照路径，另 10000 条供各失效设定共用。共 **40,000 条基础噪声路径**；两个 Sharpe 与各方法共享相应噪声以形成配对，因此各设定之间**不是**互相独立的样本。
- 随机 T 使用独立随机流，并在相关方法之间共用。

**本轮不重新拟合门槛。**下文所有区间描述的是“给定既有冻结门槛时的测试不确定性”，**不能**声称重新覆盖了校准误差。

## 3. 评价定义

```
    失效前误杀      P(tau <= T)
    条件检出        P(T < tau <= T+h | tau > T)
    联合检出        P(T < tau <= T+h)
```

h ∈ {63, 126, 252} 个交易日。**主要比较保持相同的失效后观察长度**，不让不同 T 隐含不同的检测机会。

从不报警编码为 τ=∞。它是失效前窗口的**存活者**、失效后的**未检出**路径，**不是**提前误杀。联合检出恒等式 `联合 = 存活率 × 条件检出` 在每一行上核验，本轮全表最大偏差 **5.55e-17**。

失效后延迟为 `E[min(τ−T, 252)]`，条件于 τ>T，分母是**全部存活到 T 的路径**：未检出的存活者按窗口上限计入而不是删去，提前误杀的路径不计为零延迟。失效后中位时间同样以全部存活者为分母，取累计比例首次达到一半的那一天。

**252 日 trailing Sharpe 在 T=252 处同时误杀更少、条件检出与联合检出更高，这是本设定下的实测事实。** 但本轮**没有**分解这个优势的来源。至少有四条机制可能同时起作用，它们的相对份额未被测量：

1. **启动期**：它最早只能在第 252 天说话，因此在 T=0 时失效后窗口里只有第 252–252 天可用，而在 T=252 时启动期恰在失效时刻走完。同一件事也限制了它在失效前的报警机会：T=252 时它在失效前只有第 252 天这一天可能报警（实测误杀 2.28%，普通 EWMA Student-t 为 6.76%）。
2. **滚动窗口会逐步移除失效前的数据**：失效之后，有利的历史证据会随窗口滑出，而累计型模型不会自动丢弃它。
3. **方差状态**：EWMA 类方法在失效时刻带着一个由过去数据形成的方差估计。
4. **存活者筛选**：条件统计只在没有被提前误杀的路径上计算，各方法的存活集合不同。

因此**不能**把这个优势归因于其中任何单独一条，也不能据此断言“它的判别能力更强”或“它的优势只是窗口对齐”——两种说法本轮都没有证据支持。

其二，若累计型模型在较晚失效时变慢，**不要把全部差异都归因于历史证据**：初始化、方差状态与存活筛选（只有没被提前误杀的路径才进入条件统计）都会影响表现，本轮没有分解它们各自的份额。

## 7. 直接回答

**（一）从“上线即无效”迁移到“先有效、后失效”时有什么变化？** 在主设定下，把 T 从 0 移到 252 天后，同样 252 天的观察窗口内：固定 Student-t 的联合检出由 20.24% 变为 15.58%；普通 EWMA Student-t 的联合检出由 25.95% 变为 19.75%。

变化来自三处，本报告分开列出而不是合成一个数字：（i）失效前的误杀会先消耗掉一部分路径（本设定下 6.76%，这些路径在 T 之前就被判无效，属于误杀而非检出）；（ii）存活下来的路径带着一段**有利的历史证据**进入失效时刻（第 6 节的 U_T、q_T）；（iii）滚动型方法的启动期在较晚的 T 下已经走完。

主设定下联合检出最高的是 252 日 trailing Sharpe（24.23%）。

**一个随失效时间改变方向的比较。** 普通 EWMA Student-t 相对 252 日 trailing Sharpe 的联合检出差，在 T=252 时为 -4.48 pp [-5.46, -3.49]，而在随机 T 下为 +4.22 pp [+3.25, +5.13]——两个区间都排除 0，**方向相反**。本轮只测了 T ∈ {0, 126, 252} 与随机 T 四个设定，**没有**扫描 T，因此不能说 T=252 是对 252 日 trailing Sharpe 全局最有利的失效时刻。能记录的是：**方法排序随失效时刻改变**，成因见上一节列出的四条未分解机制。

**（二）这些结果是否足以支持本周向导师说明适用范围？** 可以说明的是：本项目现有的五个检测器在“先有效、后失效”这一设定下仍然可用，并且失效前误杀、条件检出、联合检出三个量已经被分开测量与报告；覆盖范围是 T ≤ 252 天、两个噪声情境、两个信号强度、两个误杀预算。**不能**据此说明更长寿命（数年）的表现，也不能说明任何未纳入本项目的方法。

**（三）哪些问题应留给导师决定下一周是否继续？** 本报告不替这些问题作答：

1. 失效时间的覆盖范围是否要从一年扩展到数年——那需要更长的模拟期限，并会改变“两年监测”这个主基准的含义。
2. 是否需要一个显式建模状态切换的检测器（而不是继续用静态两状态分类器的工作失效分数）——本轮的证据只说明静态分类器在切换数据上仍能工作，没有比较过任何切换感知的方法。
3. 失效前误杀与失效后延迟之间的权衡应当按什么代价函数取舍——本项目至今只报告两者，没有为它们赋权，等待成本也未纳入评价。

## 8. 限制

- 覆盖范围是 T ≤ 252 天（一年内失效），不是 0–5 年或 0–10 年的寿命研究。
- 门槛沿用 Stage 3A 的 504 日冻结值；区间只描述测试抽样，不覆盖校准误差。
- 各失效设定共用同一批基础噪声，设定之间不是独立样本。
- 静态分类器的 q 是工作失效分数，不是对切换过程的正确后验。
- 解析恒等式只在 iid 高斯、固定 T、全部路径上核验过。
- 本轮不实现 BOCPD，也不新增任何检测模型或扩大参数范围。
