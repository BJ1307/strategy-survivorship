# mixed_noise 实验报告：每条策略的噪声参数都不同

由 `python -m strategy_survivorship.run_mixed_noise` 自动生成，所有数字取自同一次运行的结果表。**本轮没有新增任何检测模型。**

## 1. 运行前写定的设计

```
    A_i     ~ Uniform(0, 1)   波动起伏幅度
    kappa_i ~ Uniform(0, 8)   跳跃尺度
    rho = 0.98    lambda = 2/年    潜在 AR(1) 从平稳分布起步
    有效 Sharpe = 1，无效 = 0，先验各 0.5
    D = 252，H = 504，两年累计误杀预算 = 0.15
```

四个参数的角色不同，不要混：**A** 控制波动起伏的幅度；**rho** 控制一个波动水平能持续多久；**kappa** 控制单次跳跃有多大；**K** 是某一天落下几次跳跃。

每条策略只抽一次 (A, kappa)，整个观察期固定，且**独立于状态与全部噪声流**。监测器看不到它们，只看到收益。

**范围声明。** 这两个取值范围是运行前写定的**模拟选择**，不是从任何市场估计出来的，也不是导师指定的。

## 2. 归一化与门槛

- 标准化用的是**该路径自己 kappa 对应的理论常数** `sqrt(1 + kappa_i^2 * lambda/D)`；**没有**按路径的样本均值或样本方差重新标准化。
- 三个批次各 10000 条，参数与噪声**逐批独立抽取**；两个测试批次在所有方法之间共享，因此比较是配对的。
- 每种方法在**整个混合总体**上只校准一个门槛，然后冻结：规则数 5、δ = 0.05、δ/规则 = 0.01、秩 **1417**（二项式与 Beta 两路一致）。
- 门槛**没有**使用真实 A、kappa、事后分组或测试结果。

**这个预算保证的范围**：a cumulative false-alarm budget for the WHOLE mixture; it is not the same guarantee at every parameter point, and it is not an at-least-one-alarm guarantee across a portfolio of monitored strategies

## 4. 两个预设比较（504 日）

1000 次配对 bootstrap，重抽单位是整条路径，校准与测试同时重抽，**每次重新校准门槛**；同一批次内各方法共用重抽下标。区间为逐项 95% 区间。

| 比较 | 量 | 点估计 | 95% 区间 | 排除 0 |
|---|---|---|---|---|
| 固定 Student-t − 固定 Gaussian | 检出率 | +4.94 pp | [+3.96, +6.09] | 是 |
| 固定 Student-t − 固定 Gaussian | 误杀率 | +0.24 pp | [-0.60, +1.04] | 否 |
| EWMA Student-t − 固定 Student-t | 检出率 | +1.00 pp | [-0.24, +1.88] | 否 |
| EWMA Student-t − 固定 Student-t | 误杀率 | -0.14 pp | [-1.08, +0.60] | 否 |

**读法。** 重尾似然的收益在混合总体里仍然测得到：+4.94 pp [+3.96, +6.09]，且同预算下的误杀差区间覆盖 0，即这份收益不是用更多误杀换来的。

**EWMA 相对固定 Student-t 的收益在这里测不出来**：+1.00 pp [-0.24, +1.88]，区间覆盖 0。

**但不要把这个差异全部归因于参数随机化。**相对此前的固定情境实验，本轮同时改变了两件事：(一) 每条策略的参数不同；(二) 门槛从按情境分别校准改成整个混合总体只用一个。本轮没有设计实验去分离这两者的贡献。

## 6. 限制

- 全部为模拟。独立测试路径确实是样本外评估，**但它们来自与校准路径同一个生成模型族**；随机化参数**没有**解决真实市场的泛化问题。
- 参数范围是运行前的模拟选择，不是市场估计。
- 只做了一个误杀预算（0.15）、一个信号强度（Sharpe 1 对 0）、策略从上线起状态不变；本轮不含随机失效时间。
- 区间为逐项区间，未做多重比较校正。
- 子群表用的是同一个冻结门槛读回，不是按子群重新校准的结果。
