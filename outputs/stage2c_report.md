## 2. 校准协议（运行前固定）

覆盖集合为 **5 种完整路径生成规律**：高斯、厚尾 t(5)、SV ρ=0.98、跳跃 κ=5、SV ρ=0。
每种情境 10000 条有效校准路径，**各方法共享同一批校准路径**，使用本轮专属独立随机流。

构造：设一条有效路径在监测期内的最小统计量为 `M`，报警规则为**统计量严格小于门槛**，于是一条路径报警当且仅当 `M < c`，门槛 `c` 的真实 FAR 就是 `M` 的 CDF 值 `F(c)`。取 `c = M_(k)`（第 k 小的校准最小值），在**路径**独立同分布且 `F` 连续时

```
F(M_(k)) ~ Beta(k, N+1-k)
P{Beta(k, N+1-k) > alpha} = P{Binomial(N, alpha) <= k-1}
```

**独立单位是完整路径**，不要求同一路径内各天独立。取满足 `P{Bin(N, alpha) <= k-1} <= delta/J` 的**最大**秩 k：k 越大门槛越高、报警越多，所以最大的可行 k 是仍满足要求的最不保守选择。

| 量 | 值 |
|---|---|
| 校准路径数 N | 10000 |
| 校准失败概率总额 δ | 0.05 |
| 保证项数 J = 方法 × 情境 × 预算 | 60 |
| 每项预算 δ/J（Bonferroni） | 8.333333e-04 |
| α=0.05 的秩 k（二项路径 / Beta 路径 / 名义规则） | 433 / 433 / 501 |
| α=0.15 的秩 k（二项路径 / Beta 路径 / 名义规则） | 1389 / 1389 / 1501 |

两条路径独立计算并核对一致；所选秩满足要求而下一秩不满足，均有测试锁定。

统一门槛取 `c_unified = min_g c_g`。因为统计量越低越倾向报警，`F` 单调不减，更低的门槛只会降低 FAR，所以取最小值保留了每个情境的保证：`F_g(c_unified) ≤ F_g(c_g) ≤ α`。

> **保证的准确范围**：在上列五种完整路径生成分布及其假设成立时，校准程序以至少 95% 的概率，使所列方法与预算的**真实**两年 FAR 同时不超过各自目标。它**不**保证任意市场分布、任意参数或任意噪声规律拼接，也**不**保证每一次有限测试集观测到的 FAR 必然低于目标。本轮是针对单调路径误杀风险的**次序统计量构造**，**不是** Learn-then-Test 框架的完整实现。

**三个概率必须分开**：δ 是校准程序失败的概率；α 是策略误杀预算；测试表中的 Wilson 区间是第三个东西——有限测试集上一个比率的抽样区间。
