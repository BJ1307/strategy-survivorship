## 2. 组合 DGP（运行前固定）

```
r_t = mu_S + sigma_0 eps_t
a_t = rho a_{t-1} + sqrt(1-rho^2) xi_t,   a_1 ~ N(0,1)
v_t = exp(A a_t - A^2/2)
K_t ~ Poisson(lambda/D)
eps_t = ( sqrt(v_t) z_t + kappa sqrt(K_t) w_t ) / sqrt(1 + kappa^2 lambda/D)
```

`xi, z, w, K` 的基础随机来源相互独立；`rho = 0.98`、`lambda = 2`/年、`D = 252`、`H = 504`、年化波动率基准 0.1，有效/无效 Sharpe 为 1/0，**平均收益不随波动改变**。

**跳跃是独立加性成分**：它的幅度**不**乘以当天的背景波动，所以落在平静日上的跳跃相对更大。这是本轮要检验的设计选择。

| 情境 | SV 振幅 A | 跳跃幅度 κ | 在 Stage 2C 覆盖集内 |
|---|---|---|---|
| 高斯对照 (A=0, κ=0) | 0 | 0 | 是 |
| SV 对照 (A=1, κ=0) | 1 | 0 | 是 |
| 跳跃对照 (A=0, κ=5) | 0 | 5 | 是 |
| **SV+跳跃 (A=1, κ=5)** | 1 | 5 | **否** |
| **SV+较大跳跃 (A=1, κ=8)** | 1 | 8 | **否** |

**归一化只用理论常数**：`a_t` 边际为 `N(0,1)`，故 `E[v_t] = exp(A^2/2 - A^2/2) = 1`；两个分子项独立，方差分别为 1 与 `kappa^2 lambda/D`，因此对**任意** `(A, kappa)` 都有 `E[eps]=0`、`Var(eps)=1`。**不做任何按整条路径的样本均值或方差标准化。**

> **κ 越大不等于任务必然更难。** 单位方差常数同时压低了无跳跃日的扩散尺度。**跨全部无跳跃日的总体尺度**为 σ₀/c（因 E[v]=1）：κ=0 时 1.0000、κ=5 时 0.9135、κ=8 时 0.8143。也就是说 κ=8 的普通交易日整体上比 κ=0 **更安静**，单日信噪比反而更高。**但这是总体尺度，不是某个具体潜在状态下的尺度**——给定 v_t 时的条件尺度是 `σ₀√v_t/c`，在 A=1 下其 90/10 分位比超过 3。本轮报告不预设 κ 的单调效应。

**两个潜在方差的命名与定义**（评分与诊断用，**任何检测器都看不到，也都不是实时预测**）：

```
扩散方差（给定 v_t 且当日无跳跃）      : sigma_0^2 * v_t / c^2
给定 v_t、未观察当日跳跃的总方差        : sigma_0^2 * (v_t + kappa^2 lambda/D) / c^2
c^2 = 1 + kappa^2 lambda/D
```

> **已修正**：上一版的 `true_daily_sigma` 返回 `sigma_0 sqrt(v_t)`，漏掉了组合归一化 `c`，也没有区分是否包含跳跃风险。已逐一检查全部调用点：该量在 Stage 2D 中**只写不读**，唯一的消费者是单次冲击诊断里的一列与图 2D.4 的一条参考线；Stage 2A/2B 使用无跳跃的 SV 生成器（c=1），其 oracle 输入与全部数值**不受影响**（已重跑验证）。**因此主分数、oracle、概率评分均保持原值，只有诊断被修正。**

每个情境：10000 条有效校准路径、10000 条有效测试路径、10000 条无效测试路径；校准与测试独立，同一数据块内各检测器共用收益路径。检测器只接收收益与公共模型配置，**不获得真实状态、潜在波动、跳跃标记或情境参数**。

## 8. 单次冲击诊断

在**一条预先固定的有效 SV+跳跃路径**（路径编号 0）上，于第 126 日分别加入 ±8σ₀ 的单次收益冲击，保留未修改路径作对照；其余各日收益完全相同。

> **这是人为扰动诊断，不属于主 benchmark**，不贡献任何检出率或误杀率估计。

| 量 | 未修改 | +8σ₀ | −8σ₀ |
|---|---|---|---|
| 冲击当日 EWMA Gaussian 增量 | -0.17642 | +1.74858 | -2.10141 |
| 冲击当日 EWMA Student-t 增量 | -0.20940 | +0.05125 | -0.04284 |
| 第 126+1 日预测方差 / σ₀² | 0.2783 | 3.4145 | 4.8222 |
| 第 126+5 日预测方差 / σ₀² | 0.4410 | 2.8895 | 3.9886 |
| 第 126+21 日预测方差 / σ₀² | 0.7687 | 1.6785 | 2.0869 |
| 第 126+63 日预测方差 / σ₀² | 0.1489 | 0.2166 | 0.2469 |
| 第 504 日累计证据 (Gaussian) | +2.7958 | +4.7953 | +0.9043 |
| 第 504 日累计证据 (Student-t) | +2.8635 | +3.5032 | +3.4326 |

**验算冲击引入的方差预测差异如何衰减**：冲击把当日平方残差抬高，次日预测方差因此多出约 `(1-λ)·(8σ₀)²/σ₀² = 3.840`（以 σ₀² 为单位，忽略中点项），此后按 λ=0.94 每日衰减，半衰期 `ln0.5/lnλ = 11.2` 个交易日。实测差值见上表与 `stage2d_shock.csv`。

Student-t 在**冲击当日**把证据增量压得比 Gaussian 小得多，但**随后各日**它与 Gaussian 共用同一个被抬高的方差预测，因此同样受到影响。**本轮不把这一现象写成主要性能瓶颈**：单条人为扰动路径不足以支持那样的结论。
