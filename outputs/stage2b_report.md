## 2. 本轮模型定义（运行前固定）

```
D = 252,  H = 504,  sigma_ann = 0.1
mu_0 = 0,  mu_1 = 3.96825397e-04,  sigma_0 = 6.29940788e-03
m = (mu_0 + mu_1)/2 = 1.98412698e-04
v_1 = sigma_0^2;   v_(t+1) = 0.94 v_t + 0.06 (r_t - m)^2
```

`v_t` 是**看到第 t 天收益之前**对该天方差的预测，只用 `r_1..r_(t-1)`。不使用全样本 backcast、全路径样本方差或真实状态初始化。λ=0.94 是预先固定的简单基准，未做参数搜索。

选固定中点 `m` 是为了不读取真实状态、也不引入额外均值估计器。**代价**：在两个真实均值假设下，平方残差都多出同一个 `(mu_1-mu_0)^2/4` 项，因此这不是严格无偏的方差递推；本轮该项约为基准方差的 **0.0992%**。

两个检测器**共用完全相同的** `v_t`。更新式：

```
Gaussian :  dL_t = (mu_1 - mu_0)(r_t - m) / v_t
Student-t:  b_t = sqrt((nu-2)/nu * v_t),  nu = 5
            dL_t = log f_nu(r_t; mu_1, b_t) - log f_nu(r_t; mu_0, b_t)
```

`b_t` 是使 t 分布**方差**等于 `v_t` 的尺度参数，不是标准差。收益**没有**先按预测波动率标准化再套用固定条件 Sharpe 的假设——两个均值假设始终是收益空间的 `mu_0`、`mu_1`。

> 两个方法输出的是**各自 EWMA 条件分布假设下的模型后验**，**不是**对真实潜在 SV 状态积分之后的精确后验。

数值方差下限 `1e-08·sigma_0^2`，本轮触发 **0** 次（仅数值保护，未按测试表现调整）。

每个情境：5000 条有效校准路径、5000 条有效测试路径、5000 条无效测试路径。**Stage 2B 使用全新随机流**，所有被比较方法都在同一批新测试路径上运行；Stage 2A 结果保留不动。EWMA 从第 1 天开始，不加人为预热期。
