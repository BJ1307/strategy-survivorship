## 1. 本轮结论

**冻结 Stage 1 门槛后，噪声改变会把实际误杀率推离名义预算。** 在名义 α=0.15 下，两年实测误杀率：高斯对照 0.1378、厚尾 0.1492、随机波动率 0.1380、跳跃 0.1600（Binary Gaussian）。完整四检测器 × 四情境见第 4 节。

**按情境重新校准可以把误杀率拉回预算附近，但这是理想化设定。** 它假设噪声情境事先已知；本轮**没有**任何检测器在未知环境下自适应，重新校准臂只回答「如果环境已知，性能上限在哪里」。

**知道当期方差能带来多少帮助（随机波动率情境）**：oracle 两年检出率 0.7904，固定波动率 Binary Gaussian 0.5756，差 +0.2148。oracle 使用真实当期条件方差，**任何可部署规则都拿不到这个信息**，它只标定一个上界。

## 2. 实验定义（在看结果前固定）

```
r_t = mu_S + sigma_0 * eps_t,   mu_S = S*sigma_ann/D,   sigma_0 = sigma_ann/sqrt(D)
S in {0, 1},  D = 252,  sigma_ann = 0.1,  H = 504 交易日
```

四种 eps 全部**零均值、单位无条件方差**，归一化只用理论常数，**不做任何按路径样本均值/标准差的事后标准化**（那会改变生成机制并把未来数据带入构造）。

| 情境 | 定义 | 参数 |
|---|---|---|
| 高斯（对照） | `eps = z`, `z~N(0,1)` | — |
| 厚尾 | `eps = sqrt((nu-2)/nu) * X`, `X~t_nu` | ν = 5 |
| 随机波动率 | `a_t = rho a_{t-1} + sqrt(1-rho^2) xi_t`, `a_0~N(0,1)`; `v_t = exp(a_t - 1/2)`; `eps = sqrt(v_t) z_t` | ρ = 0.98, 振幅 1 |
| 跳跃 | `K_t~Poisson(lambda/D)`; `eps = (z + kappa*sqrt(K)*w)/sqrt(1+kappa^2 lambda/D)` | λ = 2/年, κ = 5 |

单位说明：**λ 是年度跳跃强度**（每年期望跳跃次数），日强度为 λ/D；**κ 是单次跳跃的标准差**，以日高斯冲击为单位。

> 这些参数是**研究压力情境**，不是对任何市场的拟合，也不声称能复现真实市场。主实验一次只加入一种噪声特征，不做完整组合网格。有效状态表示**长期** Sharpe 为 1；在随机波动率下逐日条件 Sharpe 必然变化，本轮不要求它恒等于 1。

每个情境使用独立的 5000 条有效校准路径、5000 条有效测试路径、5000 条无效测试路径；同一情境下各模型评价**同一批**测试路径。

## 3. 噪声诊断

误差为**路径级**（路径之间独立，路径内的交易日不独立——ρ=0.98 时对数方差半衰期约 34 天，把所有 path-day 当独立样本会严重低估误差）。

自相关一律**跨路径池化、用全局均值去心**。按每条路径自己的样本均值去心会把携带持续性的低频成分一起减掉：实测下它把 |ε| 的一阶自相关低估约 21%、四十阶低估约 47%，并把 AR(1) 估计拉到设定 ρ 以下约 23 个标准误。池化估计与设定值一致。

随机波动率：对数方差一阶自相关 **0.98024 ± 0.00015**（设定 ρ = 0.98，相差 1.6 个标准误）；|ε| 一阶自相关 **0.27318 ± 0.00191**，对应的**解析总体值为 0.27300**（相差 0.10 个标准误）；真实日波动率的 90/10 分位比 3.62。
跳跃：实测日均跳跃数 0.00796（理论 0.00794），含跳跃交易日占比 0.0079。

Student-t 的样本峰度在 ν=5 下抽样方差不存在，**未**用作验收统计量；改用尾部频率。
